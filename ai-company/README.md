# ノウハウ実行キット

買ったのに実行できていない商材を、AI（Claude Code）に代わりに実行させるためのキットです。

**読まなくても、理解していなくても動きます。** 手順は3つだけ。

---

## 使い方（3手）

### 1. このフォルダを好きな場所に置く

zip で受け取った場合は解凍するだけ。

### 2. `materials/` に商材を入れる

PDF でも、テキストでも、動画の書き起こしでも、URLをメモしたテキストでも構いません。
複数入れても大丈夫です。**中身を整理する必要はありません。**

```
materials/
  買った教材.pdf
  セミナーメモ.txt
```

### 3. このフォルダでターミナルを開いて `claude` と打つ

```bash
cd ai-company
claude
```

以上です。あとは AI が勝手に、

1. 商材を読んで棚卸しする
2. 実行できる手順書に変換する
3. その手順書を自分でレビューして直す
4. 実際に実行する
5. 繰り返しになる部分を自動化する

まで進めます。**あなたから指示を出す必要はありません。**

---

## 事前に必要なもの

- Claude Code がインストールされていること
  （未導入なら [claude-code-textbook.md](../claude-code-textbook.md) の「5分で入れる」を参照）

---

## 途中でやめて、また再開できます

進捗は `work/state.md` に残っています。
次に `claude` を起動すると、AI はそれを読んで続きから始めます。

---

## AI が絶対にやらないこと

事故防止のため、以下は **自動実行しません**。

- SNS への投稿
- メール・DM の送信
- 記事・ページの公開
- 支払い・課金
- ファイルの削除

これらは `work/drafts/` に下書きが置かれるので、**あなたが目で見て、あなたが出してください。**

---

## 成果物はどこに出るか

| 場所 | 中身 |
|---|---|
| `work/outputs/` | 完成したもの |
| `work/drafts/` | あなたの確認待ち（投稿文など） |
| `work/state.md` | いまどこまで進んだか |
| `.claude/skills/` | 商材から変換された手順書 |
