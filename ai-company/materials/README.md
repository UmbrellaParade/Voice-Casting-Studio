# ここに教材を入れてください

買った教材・セミナー資料・ノウハウを、このフォルダにそのまま置いてください。

## 置けるもの

- PDF
- テキストファイル（.txt / .md）
- 動画・音声の書き起こしテキスト
- 教材ページや会員サイトの URL を書いたテキストファイル
- スクリーンショット画像

## やらなくていいこと

- 中身を読む
- 要点をまとめる
- ファイル名を整える
- フォルダを分ける

**そのまま放り込んで大丈夫です。** 整理は AI 側でやります。
