# work/ — 作業フォルダ

AI が作業中に使う場所です。**あなたが触る必要はありません。**

見るとしたら、この2つだけで足ります。

| 見る場所 | 何が分かるか |
|---|---|
| `state.md` | いまどこまで進んだか |
| `drafts/` | あなたの確認待ちのもの（投稿文など） |

## 各フォルダ

| 場所 | 中身 |
|---|---|
| `state.md` | 現在フェーズ・完了ステップ・次にやること |
| `inventory.md` | 商材の棚卸し結果 |
| `dropped.md` | 実行に寄与しないので捨てた内容 |
| `review.md` | 自動レビューで残った指摘と、残した理由 |
| `automation.md` | 登録した自動化と、その解除方法 |
| `outputs/` | 完成した成果物 |
| `drafts/` | **人間の最終確認待ち**（公開・投稿・送信するもの） |
| `log/` | 日付ごとの作業ログ |

## `drafts/` について

SNS投稿・メール・公開記事などは、AI は自動で出しません。
ここに下書きが置かれるので、**中身を読んで、あなたの手で出してください。**
